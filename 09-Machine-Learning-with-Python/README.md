# 09 - Machine Learning with Python

This folder contains the labs, practice notebooks, and final project completed for Course 9 of the IBM Data Science Professional Certificate.

## Contents

### Regression
* `Simple-Linear-Regression.ipynb` - Simple linear regression models.
* `Multiple-Linear-Regression.ipynb` - Multiple linear regression models.
* `Regularization_in_LinearRegression.ipynb` - Applying regularization techniques to linear regression.

### Classification
* `KNN_Classification.ipynb` - K-Nearest Neighbors classification.
* `Decision_trees.ipynb` - Decision tree classification.
* `Logistic_Regression.ipynb` - Logistic regression models.
* `decision_tree_svm_ccFraud.ipynb` - Decision tree and SVM comparison for credit card fraud detection.
* `Multi-class_Classification.ipynb` - Handling multi-class classification problems.

### Clustering
* `K-Means-Customer-Seg.ipynb` - K-Means clustering for customer segmentation.
* `Evaluating_k-means_clustering-Copy1.ipynb` - Evaluating K-Means clustering performance.
* `Comparing_DBScan_HDBScan.ipynb` - Comparing DBSCAN and HDBSCAN clustering algorithms.

### Dimensionality Reduction
* `PCA.ipynb` - Principal Component Analysis.
* `tSNE_UMAP.ipynb` - t-SNE and UMAP dimensionality reduction.

### Model Evaluation and Pipelines
* `Evaluating_random_forest.ipynb` - Evaluating Random Forest models.
* `ML_Pipelines_and_GridSearchCV.ipynb` - Building ML pipelines and using GridSearchCV for hyperparameter tuning.

### Final Project & Practice
* `FinalProject_AUSWeather(1).ipynb` - Final project predicting rainfall in Australia.
* `Practice Project.ipynb` - Practice project for the course.

### Miscellaneous
* `login(2).ipynb` - Notebook for Watson Studio login/authentication.
