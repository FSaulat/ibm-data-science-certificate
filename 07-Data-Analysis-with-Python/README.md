# 07 - Data Analysis with Python

This folder contains the labs, practice notebooks, and projects completed for Course 7 of the IBM Data Science Professional Certificate.

## Contents

### Module 1: Importing Datasets
* `DA0101EN-Review-Introduction.ipynb` - Course introduction and review.
* `Practice_data_loading.ipynb` - Practice exercises for importing data using Pandas.

### Module 2: Data Wrangling
* `DA0101EN-2-Review-Data-Wrangling.ipynb` - Review of data preprocessing and cleaning.
* `practice_data_wrangling.ipynb` - Hands-on practice with data wrangling techniques.

### Module 3: Exploratory Data Analysis
* `Exploratory_data_analysis_cars.ipynb` - EDA on a car dataset.
* `parctice_Exploratory_data_analysis.ipynb` - General EDA practice notebook.

### Module 4: Model Development
* `DA0101EN-4-Review-Model-Development.ipynb` - Review of building regression models.
* `Model_Evaluation_and_Refinement_cars.ipynb` - Evaluating and refining models using the car dataset.
* `practice_model_development_laptops.ipynb` - Building models using a laptop pricing dataset.
* `practice_model_evaluation.ipynb` - Practice with model evaluation metrics.

### Final Project
* `House_Sales_in_King_Count_USA(1).ipynb` - Final project analyzing house sales data.
* `practice_project.ipynb` - Practice run for the final project.

### Miscellaneous
* `lab.pdf` - Course lab instructions/documentation.
