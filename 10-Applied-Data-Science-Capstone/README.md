# 10 - Applied Data Science Capstone

This folder contains the labs, data collection scripts, and predictive models completed for the final course of the IBM Data Science Professional Certificate.

## Contents

### Data Collection
* `jupyter-labs-spacex-data-collection-api.ipynb` - Collecting launch data using the SpaceX API.
* `jupyter-labs-webscraping.ipynb` - Scraping launch data from Wikipedia.

### Data Wrangling & EDA
* `labs-jupyter-spacex-Data wrangling.ipynb` - Cleaning and preparing the SpaceX dataset.
* `jupyter-labs-eda-sql-coursera_sqlite.ipynb` - Exploratory Data Analysis using SQL queries.
* `jupyter-labs-eda-sql-coursera_sqlite(1).ipynb` - Duplicate/alternate version of the SQL EDA lab.
* `edadataviz.ipynb` - Exploratory Data Analysis using data visualization.

### Interactive Visual Analytics
* `lab_jupyter_launch_site_location(1).ipynb` - Geospatial analysis using Folium.
* `dash_interactivity.py` - Python script for the interactive Plotly Dash dashboard.

### Predictive Analysis
* `SpaceX_Machine Learning Prediction_Part_5(1).ipynb` - Building machine learning models to predict landing success.
