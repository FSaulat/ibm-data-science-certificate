# IBM Data Science Professional Certificate

## Course 6: Databases and SQL for Data Science with Python

### About This Repository

This repository contains the lab files, Jupyter Notebooks, and assignments for Course 6 of the IBM Data Science Professional Certificate on Coursera.

**Course Description:**
Much of the world's data resides in databases. SQL (Structured Query Language) is a powerful language used for communicating with and extracting data from databases. In this course, I learned how to analyze data within a database using SQL and Python, create relational databases, and compose advanced queries.

### Learning Objectives Covered

Based on the course syllabus, this module covers:

* Analyze data within a database using SQL and Python.
* Create a relational database and work with multiple tables using DDL commands.
* Construct basic to intermediate level SQL queries using DML commands.
* Compose more powerful queries with advanced SQL techniques like views, transactions, stored procedures, and joins.

### Skills Gained

SQL, Data Manipulation, Relational Databases, Jupyter, Transaction Processing, Python Programming, Stored Procedures, Database Management, Query Languages, Databases, Data Access, Data Analysis.

## Repository Contents (Module 6 Focus)

The files in this repository represent the practical lab work for the final module of the course.

| File Name | Description |
| :--- | :--- |
| **DB0201EN-Week3-1-4-Analyzing_SQLite.ipynb** | Demonstrates how to connect to a SQLite database using Python's `sqlite3` library. It covers running queries, fetching results into pandas DataFrames, and performing data analysis. |
| **SQLiteMagic.ipynb** | Introduces the `%sql` magic command using `ipython-sql`. This allows writing SQL queries directly into Jupyter Notebook cells for a faster workflow. |
| **Week4_Insert_Update_SQLite.ipynb** | A practical exercise focusing on Data Manipulation Language (DML). It demonstrates how to `INSERT`, `UPDATE`, and `DELETE` records within a SQLite database. |
| **DB0201EN-Week4-1-1-RealDataPractice-v5.ipynb** | The comprehensive final assignment. It involves working with real-world datasets (e.g., Chicago Census/Socioeconomic data), utilizing SQL joins, aggregations, and Python to answer analytical questions. |
