# Data Science Final Assignments

This repository contains a collection of Jupyter Notebooks created for the Data Science Final Assignments. It demonstrates skills in web scraping, library usage, data manipulation, and building interactive dashboards.

## Repository Contents

*   **Final Assignment Webscraping.ipynb**
    *   Demonstrates techniques for extracting data from web sources using Python libraries such as BeautifulSoup or Requests.
    
*   **Final_Assignment Library.ipynb**
    *   An exploration and application of essential Python data science libraries (e.g., Pandas, NumPy, Matplotlib) to solve specific problems.

*   **Revenue Data and Building a Dashboard.ipynb**
    *   A comprehensive analysis of revenue data culminating in the creation of a dashboard to visualize key business metrics and trends.

*   **README.md**
    *   Project documentation.

## Technologies Used

*   Language: Python
*   Tools: Jupyter Notebook / Google Colab
*   Libraries: Pandas, NumPy, Matplotlib, Seaborn, BeautifulSoup
